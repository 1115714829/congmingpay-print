二、术语与约定

2.1 术语表

术语说明
本服务聪明付票据打印服务器（Windows 端程序），MQTT 客户端角色
短商户号（merchant）上行 JSON 字段名固定为 merchant，语义为本端来源标识，各通道取值不同但各自体系内唯一：自建＝聪明付短商户号（仅字母数字下划线，兼下行订阅主题与 ClientID）；云消息队列＝设置页「自定义 ID」；物联网平台＝DeviceName（设置页无商户号字段，Topic 路径亦含 ProductKey/DeviceName）
云盒兼容模式本服务系统设置中的开关，默认开启。开启时：接受 type=5（等同 0）；buzzer／cut／reprint／headLines／tailLines 可省略；接受 contents 中的 cut 元素（5.10）；打印回执仅发布 done／failed。关闭时：type 仅 0／1；上述五字段必填；contents 中出现 cut 元素整单拒绝；打印回执发布完整事件（含 accepted／waiting）。详见 4.2、4.5、5.10、6.2
上报主题本服务发布全部上行消息的 MQTT 主题。自建：设置页手填；云消息队列：{父主题}/{自定义ID}/{上行后缀}；物联网平台：/{ProductKey}/{DeviceName}/user/{上行后缀}
打印机本服务中登记的一台热敏小票打印机（网口或 USB）
任务一次打印请求经受理后生成的打印作业，以任务号（jobNo）标识
打印回执（report）上行消息之一：打印请求的受理与执行结果，event 字段区分阶段（受理／卡单／成功／失败）
状态快照（state）上行消息之一：服务在线状态与全部打印机（配置参数＋在线状态）的全量快照
错误码（code）全局分段数字码，0＝成功，非 0 时首位数字表示阶段，见第七章
整单拒绝打印请求中任一内容非法时，整条请求不打印，打印回执 event 为 failed 并携带错误码
纸宽热敏纸宽度，取值 58 或 80（毫米）。58mm 每行 32 字符，80mm 每行 48 字符（中文按 2 字符计）

2.2 数据约定

  • 报文均为 UTF-8 编码的 JSON。
  • 字段表中「必填」列：必填＝缺失即拒绝；可选＝缺失时按「默认」列取值。默认值仅决定本单打印行为，省略的字段不写回打印机配置（写回规则见 4.4）。
  • 严格校验总则：字段缺失时按本文档声明的默认值处理（合法）；字段存在但取值非法时整单拒绝，不应用默认值、无降级。显式 null 视作字段缺失。仅校验被该元素实际消费的字段。

三、通信通道

3.1 连接参数

本服务设置页以选项卡三选一：自建 MQTT、云消息队列 或 物联网平台（provider=generic／aliyun／iot），同时只连接一种。

3.1.1 自建 MQTT

参数说明
协议MQTT 3.1.1，明文 TCP
Broker 地址／端口由本服务设置页配置，端口默认 1883
鉴权用户名／密码
ClientID填写短商户号
KeepAlive60 秒
会话CleanSession；断线自动重连（重连间隔最大 30 秒），重连后自动恢复订阅
QoS订阅与发布均为 QoS 1
遗嘱（LWT）主题＝上报主题，内容＝简版状态快照（服务离线，见 6.3）

3.1.2 云消息队列 MQTT 版

参数说明
协议MQTT 3.1.1，明文 TCP
阿里云 MQTT 地址／端口设置页手填控制台接入点域名与端口（默认 1883）
鉴权Username=Signature|{AccessKeyId}|{InstanceId}，Password=Base64(HMAC-SHA1(SecretKey, ClientID))（RAM 子用户 AccessKey）
ClientID{GroupId}@@@{自定义ID}（Group 须在控制台创建；自定义 ID 为商户号，全局唯一）
InstanceId／AccessKey／SecretKey／GroupId设置页必填
KeepAlive／会话／QoS／LWT与自建相同

3.1.3 物联网平台（一机一密）

参数说明
协议MQTT 3.1.1，明文 TCP（securemode=3）
接入点默认 {ProductKey}.iot-as-mqtt.{RegionId}.aliyuncs.com；亦可手填覆盖
鉴权设备证书：ProductKey／DeviceName／DeviceSecret。Username=DeviceName&ProductKey；Password=hex(HMAC-SHA1(DeviceSecret, content))，content 为 clientId／deviceName／productKey／timestamp 按参数名字典序拼接
ClientID{ProductKey}.{DeviceName}|securemode=3,signmethod=hmacsha1,timestamp=…|
设备列表设置页「获取设备列表」为预留占位，当前须手填设备三元组
KeepAlive／会话／QoS／LWT与自建相同

3.2 主题

3.2.1 自建 MQTT

方向主题内容
下行（本服务订阅）<短商户号>打印消息：单个 JSON 对象或对象数组（见第四章）
上行（本服务发布）上报主题两类上行消息：打印回执 report 与状态快照 state（见第六章），全部携带 merchant 字段

单主题一对多模型：服务端可仅使用一个上报主题（例如 server）接收全部客户端的上行消息，按消息内 merchant 字段区分来源；各客户端的下行订阅主题（短商户号）相互独立。

上报主题约束：为完整发布主题，可包含 /；不得包含通配符 +、#；不得等于订阅主题（短商户号），否则上行消息将被本服务自身接收并形成消息循环。

3.2.2 云消息队列（父主题 + 自定义 ID + 后缀）

设置页填写父主题、自定义 ID、下行后缀、上行后缀，自动拼接为 {父主题}/{自定义ID}/{下行后缀} 与 {父主题}/{自定义ID}/{上行后缀}。示例：父主题=server，自定义 ID=M100001，下行=cmd，上行=report → 订阅 server/M100001/cmd，上报 server/M100001/report。

约束：父主题须为控制台已创建的一级 Topic；子路径无需逐条创建；全路径长度 ≤ 64；不得含 +／#；订阅与上报不得相同。上行 merchant＝自定义 ID。云端可对上报使用通配（如 server/+/report）。

3.2.3 物联网平台

设置页填写下行／上行后缀，自动拼接为官方自定义 Topic：订阅 /{ProductKey}/{DeviceName}/user/{下行后缀}，上报 /{ProductKey}/{DeviceName}/user/{上行后缀}。示例：ProductKey=a1pk，DeviceName=printer01，下行=cmd，上行=report → 订阅 /a1pk/printer01/user/cmd，上报 /a1pk/printer01/user/report。约束：后缀不得含 +／#；订阅与上报不得相同（后缀须不同）。控制台须已为该设备授权对应自定义 Topic。上行 merchant＝DeviceName。

3.3 投递语义

  • 上行发布为尽力送达：不排队、不补发。MQTT 未连接或发布失败时，消息丢弃，原因记录于本服务日志文件 congmingpay.log。
  • 断线期间产生的上行消息不可恢复。状态快照（state）为定时全量上报（见 6.3），单条丢失由后续周期自动补齐；服务端可按「超过约 2.5 分钟未收到 state」判定客户端异常，并结合打印回执（report）自行兜底。

四、下行接口

下行报文按顶层字段分流：顶层 query 为非空字符串的单个对象为查询消息（见 4.6）；其余为打印消息（单个打印请求对象，或打印请求对象的数组）。

4.1 打印消息报文结构

消息 payload 为一个打印请求对象，或打印请求对象的数组。数组中每个元素为一条独立请求，各自受理、各自回执，互不影响；本服务不做去重，收到的每条请求均会处理。

字段类型必填默认说明
printer字符串 或 对象与 gateway 二选一—打印目标。字符串＝已登记打印机的名称或 ID（网口与 USB 通用）；对象见 4.1.1
gateway字符串与 printer 二选一—网口地址 IP 或 IP:端口（端口缺省 9100）。仅承载网口地址；USB 打印机以 printer 指定名称或 ID
id整数可选0请求标识，取值 0–4294967295。仅用于回执与日志对应，不用于去重。建议使用非 0 值且每单唯一
type整数可选0内容类型，见 4.5
pWidth整数可选按打印机登记纸宽渲染纸宽（毫米）。缺省或 0＝按打印机登记纸宽；其余取值仅允许 58 或 80，否则拒绝
pCopy整数可选1打印份数，小于等于 0 按 1 处理；每份生成一个任务，同一打印机按序打印
contents数组 或 字符串必填—打印内容：type=0 或 5 须为排版元素数组（第五章）；type=1 须为 base64 字符串。缺失或形式不符即拒绝
buzzer整数云盒兼容模式开启：可选；关闭：必填沿用打印机属性蜂鸣：0 关闭，1 开启。省略则本单沿用打印机属性、不写回
cut整数云盒兼容模式开启：可选；关闭：必填沿用打印机属性；云盒兼容模式开启且省略时，若 contents 含 type=cut 则按该元素意图切刀：0 不切纸，1 切纸。省略则本单不写回切刀属性
reprint整数云盒兼容模式开启：可选；关闭：必填0（不加重打抬头）重打标题：0 普通，1 醒目「重打」标题。省略＝不加重打抬头；不写回配置
headLines整数云盒兼容模式开启：可选；关闭：必填沿用打印机属性首部空行数（绝对值），取值 0–100；0 表示不加首部空行
tailLines整数云盒兼容模式开启：可选；关闭：必填沿用打印机属性尾部走纸偏移，取值 0–100。实际尾部走纸行数＝基数＋偏移（基数：58mm 为 5 行，80mm 为 3 行）

注：id 超出 uint32 范围（负数或大于 4294967295）会导致整条 payload 解析失败；数组 payload 中任一元素解析失败，则整个数组解析失败（见 4.2）。

4.1.1 printer 对象

字段类型说明
name字符串打印机名称。用于按名称选择已登记打印机；自动登记时作为新打印机名称，缺省时以 IP 作为名称
id字符串打印机 ID。仅用于选择已登记打印机
ip字符串网口地址。优先级高于 gateway
port字符串网口端口，缺省 9100
brand字符串品牌：佳博、飞蛾、其他。自动登记时缺省为 其他；对已登记打印机的身份覆盖仅在提供时生效，缺省不改动原值
width整数纸宽 58 或 80。自动登记与身份覆盖时使用

4.2 校验与拒绝

  • buzzer、cut、reprint、headLines、tailLines：云盒兼容模式开启时可省略（省略＝本单沿用打印机属性、不写回）；关闭时五字段均必填，缺失任一拒绝（code=2001）。若字段出现：buzzer／cut／reprint 须为 0 或 1（否则 code=2002），headLines／tailLines 须在 0–100（否则 code=2003）。pWidth 填写了非 0／58／80 的值拒绝（code=2004）。
  • type 取值非法（含云盒兼容模式关闭时的 5）拒绝（code=2005），见 4.5。
  • 顶层 cut 与 contents 中 type=cut 同时存在时，以顶层 cut 为准；仅 contents 有 cut 元素（云盒兼容模式开启）时，该意图只影响本单收尾切纸，不写回打印机切刀属性。
  • contents 内容非法时整单拒绝，规则见第五章。
  • 整条 payload 无法解析为 JSON（或字段类型不符，如 id 越界）时，本服务发布一条 event=failed、code=1001 的打印回执，其 id 为 0 且不含 jobNo，message 以「解析失败」开头。

4.3 打印目标解析

按以下顺序确定目标（printer.ip 优先于 gateway）：

  1. 网口地址（printer.ip，或 gateway 为 IP／IP:端口）：该 IP 已登记则直接使用；未登记则自动登记为新打印机。自动登记要求纸宽可确定——printer.width 或 pWidth 至少一个为 58 或 80，否则拒绝；名称缺省取 IP，品牌缺省 其他，端口缺省 9100。
  2. 名称／ID 选择器（printer 为字符串，或对象仅含 name／id）：在已登记打印机中按 ID 或名称精确匹配，未找到则拒绝。名称与 ID 与状态快照（state，见 6.3）上报的 printer／printerId 对应。
  3. printer 与 gateway 均未提供：拒绝。

USB 打印机仅可经名称／ID 选择器指定；gateway 填 "usb" 的请求拒绝（code=3003）。USB 目标不自动登记。

4.4 参数持久化（以云端为准）

每条受理成功的打印请求，对报文中已出现的下列字段覆盖并持久化到目标打印机：

  • 参数：buzzer、cut、headLines、tailLines（仅已传的项；省略则不写回）；
  • 身份字段：printer.name、printer.brand、printer.width（仅在提供且合法时覆盖，缺省不改动原值）。

reprint 为每单行为，仅对本单生效，不持久化。contents 中的 cut 元素亦不写回切刀属性。持久化后的参数以状态快照（state，见 6.3）回传。打印机属性页中的参数用于本地测试打印，并在对应字段省略时作为本单默认。

4.5 内容类型（type）

取值contents 形式处理方式
缺省 或 0排版元素数组由本服务渲染为 ESC/POS，按纸宽自适应排版（第五章）
5同 0仅云盒兼容模式开启时可用；关闭时拒绝（code=2005）
1base64 字符串解码后作为原始 ESC/POS 指令直接下发，不进行排版

其他取值拒绝（code=2005）。收尾（蜂鸣、重打标题、首部空行、尾部走纸与切纸）由本服务统一执行：优先顶层字段；云盒兼容模式开启且顶层 cut 省略时参考 contents 的 cut 元素意图。

4.6 查询消息

服务端向本服务的下行订阅主题下发查询消息，按需拉取本服务的最新状态：

{"query":"printers"}
  • 查询消息为单个对象，顶层 query 为非空字符串；不支持放入数组。
  • query 为 "printers"：本服务立即向上报主题发布一条全量状态快照（state，结构与定时上报一致，见 6.3）。
  • query 为其他取值：本服务发布一条打印回执 event=failed、code=1002、id=0。

五、排版元素规范（type=0）

5.1 总则

  • contents 为排版元素数组，按数组顺序渲染；每个元素为一个 JSON 对象。
  • 整单拒绝：任一元素含非法取值时，整条请求不打印，打印回执 event=failed、code=4001，message 格式为 渲染失败: contents[<下标>](<元素种类>): <原因>，下标为 0 基。
  • 字段缺失（含显式 null）按各元素声明的默认值处理；仅校验被该元素消费的字段，未被消费的字段忽略。
  • 元素种类由 type 字段决定；含 thead 的元素为表格（无需 type）；含 both_sides 的元素为左右两列（无需 type）。未知的 type 取值整单拒绝。

5.2 text（文本；type 缺省时的默认元素）

字段类型必填默认说明
cont字符串可选空行文本内容；缺省输出一个空行
bold布尔可选false加粗
size字符串可选不放大两位数字 "WH"，W＝宽放大档、H＝高放大档，各 0–7（"11" 表示宽高各放大一档，即二倍字）。非两位或超出 0–7 拒绝
align字符串可选leftleft、center、right；其他取值拒绝
{"type":"text","cont":"桌号：A08","size":"11","bold":true,"align":"center"}

5.3 title（标题）

字段类型必填默认说明
cont字符串可选空行标题内容

固定样式：居中、加粗、二倍字；不消费 size、align、bold。

{"type":"title","cont":"结账单"}

5.4 div_line／div_star（分割线）

字段类型必填默认说明
cont字符串可选整行填充居中标题；提供时分割线形如 ---- 标题 ----

div_line 以 - 填充，div_star 以 * 填充，宽度为整行。

{"type":"div_line"}
{"type":"div_star","cont":"二维码"}

5.5 表格（含 thead 的元素）

字段类型必填默认说明
thead对象 或 字符串数组必填—对象 {列名:"宽%"}（保持书写顺序，渲染表头行）或字符串数组 ["宽%"]（不渲染表头行）。每列宽度须为 1–100 的整数百分比（容忍 % 后缀与空白），总和必须恰为 100
tbody二维数组可选空数据行。每行单元格数必须等于列数；单元格仅接受字符串、数字、布尔（null、对象、数组拒绝）
size字符串可选不放大两位数字，规则同 text；表格取第一位作为宽高共同放大档
line_div整数可选0为 1 时每行之后输出一条 - 分割线
line_space整数可选0每行之后额外走纸的行数

约束：有 tbody 而无 thead 拒绝。单元格内容超出列宽时按显示宽度自动换行（中文按 2 计）。

{"thead":{"商品名称":"70%","数量":"15%","金额":"15%"},
 "tbody":[["青椒肉丝（标准）","1份",0.01],["规格测试","1份",0.01]],"size":"00"}

5.6 both_sides（左右两列）

字段类型必填默认说明
both_sides字符串数组必填—恰为 2 个元素：左侧文本与右侧文本，分别左对齐与右对齐；元素个数不为 2 拒绝
size字符串可选不放大两位数字，规则同 text
{"both_sides":["实付金额","0.02"],"size":"11"}

5.7 qrcode（二维码）

字段类型必填默认说明
cont字符串 或 字符串数组必填—字符串＝单码；恰含 2 项的字符串数组＝并排双码。内容为空拒绝；数组元素个数不为 2 拒绝
align字符串可选left对齐，规则同 text
size字符串可选—不消费该字段：忽略并记录警告日志，按默认模块大小渲染

约束：单码内容上限 2953 字节（QR Model 2 容量）；双码内容超出容量时因生成失败而整单拒绝。

{"type":"qrcode","cont":"https://example.com/pay/123","align":"center"}

5.8 bc128／code39（一维条码）

字段类型必填默认说明
cont字符串必填—条码内容，非空且不超过 250 字节
size字符串可选高 60 点／模块宽 2"22"＝高 90／宽 3，"33"＝高 120／宽 4；其他取值拒绝
hri整数可选0可读字符位置：0 无，1 上方，2 下方，3 上下；其他取值拒绝
align字符串可选left对齐，规则同 text

bc128 为 Code128（码集 B），code39 为 Code39；字符集兼容性由打印机固件决定。

{"type":"bc128","cont":"10132607070942533965136","align":"center","size":"22","hri":2}

5.9 png（图片）

字段类型必填默认说明
cont字符串必填—图片来源：http(s) URL，或 data:image/...;base64,<数据>
align字符串可选left对齐，规则同 text
  • 图片按内容识别，支持 PNG、JPEG、GIF 编码；渲染为单色位图（含抖动）。
  • URL 来源：下载超时 10 秒、大小上限 8MB，HTTP 状态码非 200 拒绝。
  • 下载失败、来源格式非法、解码失败均整单拒绝。

5.10 cut（切纸意图；云盒兼容模式开启时）

云盒兼容模式关闭时该元素出现即整单拒绝。开启时：

字段类型必填默认说明
type字符串必填—固定为 cut
cont字符串或整数可选1（要切）1／"1"＝本单收尾切纸；0／"0"＝本单不切

该元素不产出切纸指令，只记录本单切纸意图；本服务在收尾阶段统一走纸后切纸。顶层 cut 已传时以顶层为准。

{"cont":"1","type":"cut"}

六、上行接口

6.1 通用约定

上行消息共两类：打印回执（report）与状态快照（state）。

  • 全部上行消息发布至上报主题，QoS 1。
  • 全部上行消息携带 "merchant" 字段，标识消息来源客户端：自建＝短商户号；云消息队列＝自定义 ID；物联网＝DeviceName。字段名不变；三种通道各自体系内保持唯一。
  • 全部上行消息携带 "type" 字段标识消息类型；ts 为毫秒级 Unix 时间戳。

6.2 report（打印回执）

打印请求的受理与执行结果，统一结构，event 字段区分阶段：

event时机code携带内容
accepted请求受理成功、进入打印队列0printer＋params（本单完整上下文）
failed受理失败（解析／校验／目标／渲染）1xxx–4xxx不携带 printer
waiting打印口被占用（连接被拒）持续满 20 秒（每单至多一次）5101printer
done打印成功（数据已发送至打印机，或已提交 Windows 打印队列）0printer
failed打印执行失败（写入失败、USB 提交失败等不重试场景）5001／5002printer

每单消息序：accepted →（waiting）→ done／failed；受理失败时仅一条 failed。

云盒兼容模式开启时（默认）仅发布 done 与 failed，不发布 accepted、waiting；关闭时发布上表全部事件。

  • waiting 仅在打印口被占用（连接被拒）持续满 20 秒时发布；打印机离线导致的排队等待不发布 waiting。每单至多一次；等待期间被取消的任务不发布后续回执。
  • 在本服务界面执行「重新打印」的任务再次到达终态时重复发布（jobNo 相同）。
  • 本地操作（测试打印、打印样票）不上报。
{"type":"report","merchant":"M100001","event":"accepted","id":6812801,"jobNo":1001,
 "code":0,"message":"已提交",
 "printer":{"printerId":"p1720000000-1","printer":"飞蛾1","brand":"飞蛾","width":80,
            "conn":"network","ip":"192.168.68.194","port":"9100"},
 "params":{"buzzer":1,"cut":1,"reprint":0,"headLines":0,"tailLines":0,"pWidth":80,"pCopy":1,"contentType":0},
 "ts":1720000000000}
{"type":"report","merchant":"M100001","event":"done","id":6812801,"jobNo":1001,
 "code":0,"message":"打印成功",
 "printer":{"printerId":"p1720000000-1","printer":"飞蛾1","brand":"飞蛾","width":80,
            "conn":"network","ip":"192.168.68.194","port":"9100"},
 "ts":1720000000000}
{"type":"report","merchant":"M100001","event":"failed","id":6812802,
 "code":4001,"message":"渲染失败: contents[3](table): thead 列宽 \"abc%\" 非法(需 1-100 的整数百分比)","ts":1720000000000}
字段说明
event阶段，见上表
id回显请求的 id，字段恒存在。整条 payload 解析失败时无法取得原 id，回执 id 为 0 且不含 jobNo。建议云端使用非 0 的 id 以便区分
jobNo任务号；同一 jobNo 的各阶段回执据此关联
code全局错误码，0＝成功，非 0 见第七章
message成功为 "已提交"／"打印成功"；失败与等待为原因文本（格式见第七章）
printer打印机身份：printerId／printer（名称）／brand／width／conn／ip＋port（网口）或 usbName（USB）。受理失败的 failed 回执不携带该字段
params本单生效参数（仅 accepted 携带）：buzzer／cut／reprint／headLines／tailLines／pWidth（实际渲染纸宽）／pCopy（实际份数）／contentType（0＝JSON 排版、1＝原始 ESC/POS；请求 type=5 时回执为 0）

6.3 state（状态快照）

服务在线状态与全部打印机（配置参数＋在线状态）的全量快照；服务端以最新一条为准（幂等），无需拼装增量。

发布时机（定时上报）：①连接成功后立即发布一次；②此后每 1 分钟发布一次；③收到查询消息 {"query":"printers"} 时发布一次（见 4.6）。打印机状态与配置的变化不即时上报，最坏滞后 1 分钟；需要即时对账时服务端下发查询消息。

{"type":"state","merchant":"M100001","online":true,
 "printers":[
  {"printerId":"p1720000000-1","printer":"飞蛾1","brand":"飞蛾","width":80,"conn":"network",
   "ip":"192.168.68.194","port":"9100","online":true,"detail":"就绪(ping 3ms)",
   "buzzer":true,"cut":true,"headLines":0,"tailLines":0,
   "source":"cloud","lastPrint":"2026-07-27 15:04:05"}
 ],"ts":1720000000000}

离线为简版（本服务正常退出、MQTT 停用或连接配置变更时主动发布；异常断开时由 broker 按遗嘱发布）：

{"type":"state","merchant":"M100001","online":false}
字段说明
online本服务是否在线。false 时为简版，不含 printers 与 ts
printers[].printerId／printer打印机 ID 与名称
printers[].brand／width品牌（佳博／飞蛾／其他）与纸宽（58／80）
printers[].conn"network"（网口）或 "usb"
printers[].ip／port网口地址与端口（USB 时省略）
printers[].usbNameUSB 驱动名（网口时省略）
printers[].online／detail该打印机是否在线与可读描述（检测方式、耗时或失败原因与已持续时长）。网口打印机连续检测失败持续满 30 秒判定为离线，任一次检测成功立即恢复在线；USB 打印机状态即时生效；程序启动后尚未完成首次判定的打印机报告为离线，detail 为 检测中
printers[].buzzer／cut／headLines／tailLines每台参数当前值（云端下发覆盖后的持久化结果）。注：tailLines 为尾部走纸偏移量，本地属性页允许设置负值
printers[].source打印机来源：local（本地添加）或 cloud（云端下发自动登记）；字段缺省按 local
printers[].lastPrint上次成功打印的绝对时间（本地时区，YYYY-MM-DD HH:MM:SS）；从未成功打印过可省略或空串

七、错误码

打印回执（report）的 code 字段为全局错误码：0＝成功；非 0 时首位数字表示阶段（1 报文解析／2 字段校验／3 打印目标／4 内容渲染／5 打印执行）。message 为对应的中文原因文本，排版类错误带 contents[<下标>](<元素种类>) 定位。

code含义message 示例
1001报文解析失败（id 回 0）解析失败: <JSON 错误>
1002不支持的 query 取值（id 回 0）不支持的 query: foo(支持 "printers")
2001缺少必填字段（云盒兼容模式关闭时五字段缺失）缺少必填字段: buzzer、cut(buzzer/cut/reprint/headLines/tailLines 均必传)
2002开关取值非法buzzer 只能为 0 或 1
2003空行范围非法headLines 需在 0-100 之间
2004pWidth 非法pWidth 需为 58 或 80(或不填)
2005内容类型不支持（云盒兼容模式开启时允许 0／5／1，关闭时仅 0／1）不支持的 type: 5(仅 0=JSON 排版 / 1=ESC base64)
3001未指定打印目标未指定打印目标(printer 或 gateway 至少填一个)
3002打印机未找到未找到打印机: <名称或ID>
3003USB 目标非法USB 打印以 printer 指定打印机名称(gateway 仅支持网口 IP)
3004无法确定纸宽无法确定纸宽: 自动登记新打印机需 printer.width 或 pWidth 为 58/80(收到 printer.width=0、pWidth=0)
4001排版内容非法渲染失败: contents[3](table): thead 列宽 "abc%" 非法(需 1-100 的整数百分比)
4002排版数组非法（contents 整体非元素数组）渲染失败: <JSON 错误>
4003文本编码失败（GB18030 无法编码的字符）渲染失败: <编码错误>
4004ESC 指令解码失败（type=1）渲染失败: <base64/JSON 错误>
5001网口写入失败（终态）底层网络错误原文
5002USB 提交失败（终态）打开打印机 "..." 失败: ... 等
5101长期等待告警（event=waiting，非终态）长期等待·疑似端口未就绪/故障(请检查 IP/端口/打印机): ...
9001未知错误（兜底）—

十、补充约定

  • 自建通道：上报主题无默认值，须在设置页配置；未配置时本服务不连接 MQTT，原因记录于日志。
  • 云消息队列：须填写地址、InstanceId、AccessKey、SecretKey、GroupId、父主题、自定义 ID、下行／上行后缀；主题为 {父主题}/{自定义ID}/{后缀}。
  • 物联网平台：须填写 ProductKey、DeviceName、DeviceSecret、地域或 MQTT 地址、下行／上行后缀；主题为 /{ProductKey}/{DeviceName}/user/{后缀}；设备列表拉取为预留能力。
  • 上行消息的 type 与字段名为本服务与服务端的约定，如需调整以双方协商结果为准。
