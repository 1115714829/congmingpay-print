============================================================
 聪明付 · JSON 测试样例(粘进「JSON测试」框用)
============================================================

用法
- 每段中两行箭头标记之间(↓ 与 ↑)就是可复制的 JSON:选中它,复制,
  粘到打印机页「JSON测试」框,点「打印」。
- 目标(二选一):
    · "printer":{"name":"飞蛾1","ip":"192.168.68.194","brand":"飞蛾","width":80}
        → 带身份的对象;这台没添加过会【自动新增进打印机列表】再打印(已存在也会被下发的 5 参数+身份 name/brand/width 覆盖并持久化,见下方第 17-18 行)
    · "printer":"飞蛾1"        → 打到已注册的这台(按名称/ID)
    · "gateway":"192.168.68.194" → 只给 IP;没添加过也会自动新增(名字就用 IP)
    · 都不写 → 打到列表里当前选中的那台
- 【必填五字段,缺一即被拒(无降级)】:
    "buzzer"(蜂鸣 0关1开)、"cut"(切刀 0关1开)、"reprint"(重打抬头 0普通/1带醒目「重打」抬头)、
    "headLines"(头部空行,0=默认)、"tailLines"(尾部空行,0=默认)。
- 其中 buzzer/cut/headLines/tailLines 四个参数 + printer 身份(name/brand/width)会【覆盖并持久化】
  到目标打印机(以云端为准,属性页同步显示;本地手动改的会被下一条打印覆盖)。
  reprint 只对本单生效,不持久化。
- 纸宽:"pWidth" 填 58 或 80,按你机器改(飞蛾/佳博通用)。
- 多台:最外层是数组 [ ... ],每台一个 { }。并发打印;某台连不上只会自己
  进「等待重试」,不影响其它台。
- "id":仅用于回执与日志对应,不用于去重(每条消息都会处理并打印)。建议每单唯一便于对账。

说明
- 一次推送打多张:最外层数组 [ … ] 里放多条、都填同一台 printer/gateway,即「一次下发、
  同一台连打多张」(段6)。每条各出一张,按每台打印串行锁依次打出、互不干扰;云端下发同理。
- 打印机无需预先登记(网口):上面带 printer 身份或 gateway IP 的,没添加过的会
  自动新增进打印机列表(段2 一次发三台即一次登记三台)。**USB 目标不自动新增**,
  需先在系统装好驱动、并在本软件「新增打印机」里添加。
- 必填五字段:buzzer(蜂鸣 0关1开)、cut(切刀 0关1开)、reprint(重打抬头 0/1)、
  headLines、tailLines(0=默认)。段4/段5 已按「蜂鸣开、切刀开」填 buzzer:1 cut:1。
- 云端通道为 MQTT:真实环境把上面同样的 JSON 发到你的短商户号主题即可,格式完全一致。
